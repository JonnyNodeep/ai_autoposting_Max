# AI Content Studio for MAX

Полная спецификация проекта (MVP → SaaS)

## 1. Описание проекта

AI Content Studio for MAX — это SaaS-платформа для владельцев каналов MAX, которая полностью автоматизирует создание и публикацию контента.

Пользователь уже имеет созданный канал в MAX.

Сервис берет на себя роль полноценного AI-контент-менеджера:

- анализирует стиль канала;
- собирает пайплайн автопостинга из блоков в **AI Content Studio**;
- генерирует изображения и видео;
- помогает создать логотип канала;
- помогает написать SEO-оптимизированное описание канала;
- публикует материалы по расписанию.

Главная цель проекта — чтобы владелец канала тратил не часы ежедневно, а несколько минут в неделю.

> **Актуальный продуктовый путь:** только AI Studio Blocks. Классический Content Plan (темы → посты → publish_schedules) удалён из кода; таблицы в Postgres оставлены как deprecated. В будущем Content Plan может вернуться как отдельный тип блока в реестре.

## 2. Цель проекта

Создать лучший AI-сервис для ведения каналов MAX.

Не генератор текста.

Не генератор картинок.

Не чат-бот.

А полноценную AI-контент-студию.

---

## 3. Концепция продукта

Пользователь приходит в сервис уже имея канал.

После подключения канала AI становится его виртуальным редактором.

Сервис умеет:

- создавать контент;
- соблюдать стиль канала;
- помнить особенности автора;
- планировать публикации;
- автоматически публиковать посты после подтверждения.

---

## 4. Основные функции MVP

### Работа с каналами

- Добавление каналов.
- Название.
- Тематика.
- Описание.
- Частота публикаций.
- Стиль.
- Примеры постов.
- Генерация логотипа.
- Генерация описания канала для лучшего ранжирования в поиске MAX.

### Работа с контентом

Создание:

- текста;
- заголовка;
- CTA;
- промпта изображения;
- изображения.

### Контент-план

Создание плана на:

- 7 дней;
- 14 дней;
- 30 дней;
- 90 дней.

Сначала создаются только темы.

Пользователь:

- удаляет;
- меняет местами;
- редактирует;
- добавляет свои темы.

Только после утверждения начинается генерация постов.

### Публикация

Сценарий MVP:

ИИ генерирует публикацию

↓

отправляет владельцу

↓

Пользователь выбирает:

- Опубликовать
- Переделать
- Сделать короче
- Сделать ярче
- Сделать экспертнее
- Добавить фактов
- Удалить

↓

После подтверждения сервис публикует материал.

## 5. Что AI НЕ делает

Запрещается создавать материалы:

- политического характера;
- религиозного характера;
- связанные с военными действиями;
- нарушающие законодательство и правила платформы MAX.

Эти ограничения должны быть закреплены в системных промптах, пользовательском соглашении и оферте.

## 10. Хранимые данные

- Пользователь
- Канал
- Стиль канала
- Описание
- Примеры постов
- Контент-план
- Черновики

При этом тексты готовых публикаций не используются для долгосрочного обучения модели. Хранятся только данные, необходимые для работы сервиса и поддержания стиля канала.

## 11. Подписки

|-------|--------|
| Solo | 1 канал |
| Creator | до 3 каналов |

- генерация недоступна;

- расписание останавливается;
- данные пользователя сохраняются.

## 12. Дорожная карта разработки

### Этап 1. Основа проекта

- структура проекта;
- Docker;
- FastAPI;
- PostgreSQL;
- Redis;
- авторизация через MAX;
- система пользователей;
- система подписок;
- подключение OpenAI.

**Результат:** готовая серверная платформа.

### Этап 2. Управление каналами

- создание канала;
- описание;
- примеры постов;
- стиль;
- генерация описания;
- генерация логотипа.

**Результат:** полностью настроенный профиль канала.

### Этап 3. Генерация контента (AI Studio Blocks)

- реестр блоков + последовательный PipelineRunner;
- блоки: image_prompt, image_gen, video_gen, post_gen;
- schedule как триггер cron (не шаг execute);
- конфиг пайплайна v2 (steps + schedule), миграция со старого dict.

**Результат:** автопостинг через AI Studio.

> Content Plan (темы/утверждение/PublishSchedule) — **deprecated**, код удалён; таблицы без DROP.

### Этап 4. Редактор

Кнопки:

- Сделать короче
- Сделать длиннее
- Сделать экспертнее
- Сделать дружелюбнее
- Добавить фактов
- Переделать полностью

**Результат:** быстрая доработка без ручного редактирования текста.

### Этап 5. Планировщик

- расписание в блоке schedule AI Studio;
- cron-публикация через APScheduler;
- (исторически) очередь Content Plan / подтверждение владельцем — снято.

**Результат:** полностью автоматизированная работа канала через блоки.

### Этап 6. Оплата

**Результат:** монетизация проекта.

### Этап 8. Масштабирование

## 13. Долгосрочное развитие

После успешного запуска MVP проект развивается в полноценную AI Content Studio.

Планируемые возможности:

- UX конструктора блоков (каталог, добавить/удалить, вверх/вниз);
- блок `content_plan` в реестре (возврат плана как шага пайплайна);
- генерация музыки;
- аналитика каналов;
- AI-анализ успешности публикаций;
- рекомендации по росту канала;
- A/B-тестирование постов;
- библиотека стилей;
- маркетплейс шаблонов;
- мультиформатный контент;
- интеллектуальный автопилот, который самостоятельно ведет канал практически без участия владельца;
- DROP deprecated-таблиц Content Plan после миграции данных.

### Итоговая цель

Создать лучший AI-сервис для владельцев каналов MAX, который позволяет получать профессиональный контент, автоматизировать публикации и развивать канал с минимальными затратами времени, сохраняя высокое качество материалов и возможность дальнейшего масштабирования проекта.
